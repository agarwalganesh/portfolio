# Portfolio Website

## Project info

This is a local portfolio project built with Vite, React, TypeScript, Tailwind CSS, and shadcn-ui.

## Local development

To run the project locally, make sure you have Node.js and npm installed.

```sh
git clone <YOUR_GIT_URL>
cd <YOUR_PROJECT_NAME>
npm install
npm run dev
```

Then open `http://localhost:8080` in your browser.

## Edit this project

You can edit the source files directly in your preferred IDE. The main application entry points are:

- `src/main.tsx`
- `src/App.tsx`
- `src/pages/Index.tsx`

## Technologies used

- Vite
- React
- TypeScript
- Tailwind CSS
- shadcn-ui

## Deployment

Build the production version with:

```sh
npm run build
```

Then serve the result from `dist` or use any static hosting provider.
